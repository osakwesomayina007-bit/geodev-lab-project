# GeoDev Lab Africa Project

This project explores which communities in Eti-Osa Local Government Area have limited access to parks and sports facilities.The project aims to identify underserved communities and highlight areas that may need more recreational spaces.

Built as part of GeoDev Lab Africa, Cohort One.
See project-brief.md. for the full details.
